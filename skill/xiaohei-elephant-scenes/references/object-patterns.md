# 真实物品与物理动作模式

## 常用动作

- 拉回：绳子、挂钩、弹簧、卷尺
- 挡住：门、闸、挡板、透明罩
- 筛选：筛子、漏斗、滤网、分拣盒
- 验收：印章、放大镜、检查台、票据
- 修补：胶带、扳手、水管、补丁
- 压缩：压机、夹板、订书机、封口机
- 承接：托盘、桥板、接力棒、传送带
- 收纳：文件夹、抽屉、货架、标签盒

## 选物规则

1. 先选动作，再选物品。
2. 一个主物品优先。
3. 物品必须让小黑象能产生力学关系。
4. 物品不解释概念，动作解释概念。
5. 不能把文章名词逐个变成道具。

## 小黑象动作门槛

小黑象必须在做事：

- 象鼻卷住绳子
- 用象鼻按按钮
- 用象鼻举放大镜
- 推动闸门
- 托住掉落物
- 给卡片盖章
- 修补破裂水管
- 把卡片分拣进盒子

只是站在旁边、看着物品、拿着牌子，都不合格。
