# 真实物品与物理动作模式

## 常用动作

- 拉回：绳子、挂钩、弹簧、卷尺
- 挡住：门、闸、挡板、透明罩
- 筛选：筛子、漏斗、滤网、分拣盒
- 验收：印章、放大镜、检查台、票据
- 修补：胶带、扳手、水管、补丁
- 压缩：压机、夹板、订书机、封口机
- 承接：托盘、桥板、接力棒、传送带
- 收纳：文件夹、抽屉、货架、标签盒

## 选物规则

1. 先选动作，再选物品。
2. 先读完整段落，拆成“主旨、段落类型、处境/输入、独立信息节点、结果/边界”，再决定哪些信息必须成为可见物件、状态、动作、位置或关系。
3. 先选择密度档位：D1 只用于单一判断；D2 是解释型段落默认档；D3 用于多步骤、多条件、多角色、对比、分支或边界段落。不要把所有段落固定成 1 个主物品 + 1 个辅助物件。
4. D1 使用 1 个主物品 + 1 个辅助物件；D2 使用 1 个主物品 + 2-3 个辅助物件；D3 使用 1 个主物品/紧凑主物品组 + 3-5 个辅助物件或状态单元。每个单元都必须有段落语义职责。
5. 物品必须让小黑象能产生力学关系，或与主物品形成清晰的阶段、因果、对比、组成或边界关系。
6. 物品不单独解释概念；物品状态、空间位置、接触关系和动作链共同解释概念。
7. 不能把文章名词逐个变成道具；没有对应事实、阶段、角色、条件、结果或边界的物件直接删除。
8. 主题明确点名真实品牌、产品、平台或 App 时，优先把 logo 放在真实物品上作为识别锚点，例如 app 卡片、文件夹、文档卡、设备屏幕、终端 tile、工具盒；logo 不单独漂浮，不变成广告主角。

## 信息节点到视觉承载

每个段落节点不一定都要变成一个独立物件，但必须在画面里有可见承载：

- **输入 / 处境**：原始文件、堆积物、未通过的卡片、空容器或明显的起始状态。
- **机制 / 阶段**：筛子、闸门、工具、接触动作、空间层次、路径中的中间状态，不能只写成一个抽象名词。
- **角色 / 条件**：不同位置、不同容器、门槛、限制线、绑住/卡住/绕开的物理关系。
- **结果 / 边界**：通过托盘、已修复物、被分流的出口、断开的连接、清晰的“保留/丢弃”状态。
- **关系 / 因果**：一条主路径、接触点、前后转折、闸门或弧形回路；至少让观众知道节点之间怎样发生作用。

D2 至少覆盖 3-4 个独立节点，D3 至少覆盖 4-6 个独立节点。允许一个物件同时承载两个紧密相关节点，但不得把整段的机制、条件和结果都压到一个主题物件或一句口号里。

## 段落关系模式

按段落真实逻辑选择一个主结构，不要把所有结构同时画进一张图：

- 流程 / 因果：输入物件 -> 中间工具/阶段 -> 小黑象动作 -> 输出物件；D2 保留 3-4 个节点，D3 可用前景/中景/后景或一条路径承载 4-6 个节点。
- 对比 / 转折：左侧是原状态，右侧是结果状态；小黑象站在转折点完成动作。
- 组成 / 层级：一个主物品作为整体，D2 放入 2-3 个小物件，D3 可放入 3-5 个小物件或状态单元，分别标记组成或层级。
- 决策 / 筛选：输入物件经过闸门、筛子或检查台，输出分成“通过 / 不通过”或“保留 / 丢弃”。
- 闭环 / 反馈：用一条轻微弧形路径连接起点、反馈动作和结果；D2 保留 3-4 个节点，D3 最多 5 个物理节点，不画成复杂流程图。

每个辅助物件或状态单元都要回答“它代表段落里的哪一条信息、通过什么关系与其他节点相连”。回答不了就不画；如果段落本身有更多不可合并节点，先升级密度档位，不要用装饰物硬凑。

## 品牌物品规则

适用场景：

- 文章讨论飞书、Lark、Notion、微信、OpenAI、Codex、Claude、GitHub 等明确真实产品。
- 用户明确说“用真实品牌 logo / 用飞书 logo / 用 OpenAI logo”。
- 画面需要让读者 1 秒识别“这是哪个工具或平台”。

做法：

- 使用官方、真实、可识别的 brand logo / app icon / product mark。
- logo 放在卡片、屏幕、文件夹、入口门、工具盒或票据上，作为真实物品的一部分。
- logo 尺寸克制，只服务识别；小黑象动作和物理隐喻仍是主角。
- 不确定品牌时用中性图标，不猜 logo。

避免：

- 伪造不存在的 logo。
- 把 logo 画错、改造成相似山寨标识或恶搞标识。
- 做成品牌广告 KV、官方合作海报、赞助海报或产品发布会主视觉。
- 让 logo 大到抢走小黑象和核心动作。

## 小黑象动作门槛

小黑象必须在做事：

- 象鼻卷住绳子
- 用象鼻按按钮
- 用象鼻举放大镜
- 推动闸门
- 托住掉落物
- 给卡片盖章
- 修补破裂水管
- 把卡片分拣进盒子

只是站在旁边、看着物品、拿着牌子，都不合格。
