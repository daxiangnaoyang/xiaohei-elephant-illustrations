# 真实物品与物理动作模式

## 常用动作

- 拉回：绳子、挂钩、弹簧、卷尺
- 挡住：门、闸、挡板、透明罩
- 筛选：筛子、漏斗、滤网、分拣盒
- 验收：印章、放大镜、检查台、票据
- 修补：胶带、扳手、水管、补丁
- 压缩：压机、夹板、订书机、封口机
- 承接：托盘、桥板、接力棒、传送带
- 收纳：文件夹、抽屉、货架、标签盒

## 选物规则

1. 先选动作，再选物品。
2. 先把完整段落拆成“主旨、处境/输入、关键机制、结果/边界”，再决定哪些信息必须成为可见物件。
3. 一个主物品优先；只有当辅助物件分别承载段落信息节点时，才增加 1-3 个辅助物件，最多 4 个视觉单元。
4. 物品必须让小黑象能产生力学关系，或与主物品形成清晰的阶段、因果、对比、组成或边界关系。
5. 物品不解释概念，物品之间的关系和动作解释概念。
6. 不能把文章名词逐个变成道具；没有对应事实、阶段、角色、结果或边界的物件直接删除。
7. 主题明确点名真实品牌、产品、平台或 App 时，优先把 logo 放在真实物品上作为识别锚点，例如 app 卡片、文件夹、文档卡、设备屏幕、终端 tile、工具盒；logo 不单独漂浮，不变成广告主角。

## 段落关系模式

按段落真实逻辑选择一个主结构，不要把所有结构同时画进一张图：

- 流程 / 因果：输入物件 -> 小黑象动作或关键工具 -> 输出物件；用一条物理路径连接。
- 对比 / 转折：左侧是原状态，右侧是结果状态；小黑象站在转折点完成动作。
- 组成 / 层级：一个主物品作为整体，2-3 个小物件嵌入、堆叠或连接，分别标记组成或层级。
- 决策 / 筛选：输入物件经过闸门、筛子或检查台，输出分成“通过 / 不通过”或“保留 / 丢弃”。
- 闭环 / 反馈：用一条轻微弧形路径连接起点和结果，最多保留 3 个物理节点。

每个辅助物件都要回答“它代表段落里的哪一条信息”。回答不了就不画。

## 品牌物品规则

适用场景：

- 文章讨论飞书、Lark、Notion、微信、OpenAI、Codex、Claude、GitHub 等明确真实产品。
- 用户明确说“用真实品牌 logo / 用飞书 logo / 用 OpenAI logo”。
- 画面需要让读者 1 秒识别“这是哪个工具或平台”。

做法：

- 使用官方、真实、可识别的 brand logo / app icon / product mark。
- logo 放在卡片、屏幕、文件夹、入口门、工具盒或票据上，作为真实物品的一部分。
- logo 尺寸克制，只服务识别；小黑象动作和物理隐喻仍是主角。
- 不确定品牌时用中性图标，不猜 logo。

避免：

- 伪造不存在的 logo。
- 把 logo 画错、改造成相似山寨标识或恶搞标识。
- 做成品牌广告 KV、官方合作海报、赞助海报或产品发布会主视觉。
- 让 logo 大到抢走小黑象和核心动作。

## 小黑象动作门槛

小黑象必须在做事：

- 象鼻卷住绳子
- 用象鼻按按钮
- 用象鼻举放大镜
- 推动闸门
- 托住掉落物
- 给卡片盖章
- 修补破裂水管
- 把卡片分拣进盒子

只是站在旁边、看着物品、拿着牌子，都不合格。
