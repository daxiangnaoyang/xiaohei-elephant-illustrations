## 稳定不变量与可变变量

### 稳定不变量

- 一块平面扇面内容画布，浅蓝、灰白或暖白底，允许纸张纤维和轻微不规则边缘，但不能有真实折痕或扇片结构。
- 默认优先使用暖白纸面、轻微不规则边缘和蓝绿低饱和边缘泼墨；“扇面”是内容设计语言，不要求画出扇形轮廓。
- 中央一个主题色泼墨/刷痕色块，黑色手写大字直接成为版面第一视觉中心。
- 2-4 个手写批注，每条放在一个不规则气泡框中；气泡之间形成“问题 / 机制 / 结果或边界”的阅读路径。
- 2-4 个与主题相关的卡通简笔图标，线条轻、尺寸小，不抢主标题。
- 1-2 个朱红色手绘印章或印记，作为内容节奏点，不虚构官方印章。
- 必须有一个品牌锚点；默认小黑象，或用户明确提供的官方大象 logo，不能同时出现。

### 可变变量

- `{{TOPIC}}`：视频主题。
- `{{TITLE_TEXT}}`：从已确认文稿提炼的主标题，建议 4-8 个汉字，最多两行。
- `{{TITLE_EMPHASIS}}`：标题里 1-2 个重点词，用 `{{ACCENT_COLOR}}` 强调。
- `{{SCRIPT_CORE}}`：文稿的一句话核心判断，用于决定批注、图标和版式关系。
- `{{VISUAL_METAPHOR}}`：把文稿压缩成一个平面内容隐喻，不写成实体物品动作。
- `{{SURFACE_STYLE}}`：平面纸张/扇面内容画布的底色、纹理和版式气质。
- `{{ACCENT_COLOR}}`：橙/珊瑚红/叶绿/湖蓝等一个主色，不能同时铺多种大色块。
- `{{SIDE_NOTES}}`：2-4 条来自文稿的短批注，每条尽量 2-8 个汉字。
- `{{CALLOUT_BUBBLES}}`：批注气泡框的形状、指向和排列关系。
- `{{CARTOON_ICONS}}`：2-4 个来自文稿的卡通简笔图标。
- `{{RED_SEALS}}`：1-2 个朱红印章/印记；若有文字，只能使用已确认的短词。
- `{{BACKGROUND_CONTEXT}}`：极简浅色平面背景或纸张肌理，不使用户外实拍背景。
- `{{BRAND_ANCHOR_MODE}}`：必填，只能是“小黑象”或“官方大象 logo”。
- `{{BRAND_ANCHOR_RELATION}}`：品牌锚点与主标题、泼墨、气泡或图标的平面视觉关系。
- `{{BOTTOM_QUOTE}}`：一句短金句，放在下部安全内容区，不能被平台 UI 遮住。
- `{{STYLE_REFERENCE}}`：默认填当前唯一母版的绝对路径；只作为 `STYLE_REFERENCE_ONLY` 输入，不得作为图层或文字修复素材。
