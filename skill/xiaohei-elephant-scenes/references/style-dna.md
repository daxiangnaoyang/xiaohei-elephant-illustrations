# 小黑象 2.0 视觉 DNA

## 核心公式

```text
小黑象 + 真实物品 + 物理动作 + 短中文标签 + 留白叙事
```

## 标准模式

- 16:9 横版正文配图
- 纯白或接近纯白摄影棚背景
- 一个真实物品小现场
- 小黑象参与核心物理动作
- 2-4 个中文手写短标签
- 少量蓝 / 黄 / 红 / 橙点缀
- 留白充足，轻、怪、清爽

## 原版小黑 2.0 质感锁定

小黑象 2.0 要继承原版 `xiaohei-scenes` 的“白色空间里的真实物件小现场”，不是把小黑象做成 3D 吉祥物棚拍。生成时先锁以下不变量：

- **镜头后退一档**：标准 16:9 图里，整体场景覆盖画面宽度约 46%-58%，高度约 26%-38%。像站在白色展台前远看一个小现场，而不是贴近拍角色和物件。不要 close-up，不要把角色或主物件拍成商品大图。
- **主物品少而准**：一张图只保留 1 个真实主物品或 1 个紧凑主物品组，最多加 1-2 个小配件。不要把便签、文件夹、卡片铺满画面。
- **角色占比压低**：旧版 `xiaohei-scenes` 的小黑高度通常是画面高的 8%-13%，但它是细胳膊细腿的小黑影，黑色视觉面积很小。小黑象是低矮实体剪影，同样高度会显得重三倍。2.0 标准图必须把小黑象高度压到画面高的 3%-5%，黑色视觉体量约为此前测试图的 1/3，且不超过主物品高度的 1/3。
- **角色轻巧化**：小黑象应像“黑色哑光小剪影/软胶小执行者 + 极简白点眼”，身体小、短、轻，四肢可动，动作敏捷。不能像厚重 3D 玩具、儿童玩偶、真实动物模型、圆胖摆件或吉祥物公仔。
- **象腿锁定**：小黑象必须是四足小象。腿是 4 条短小圆桩腿，贴在身体下方，前后腿可被身体遮挡但不能只剩两条人形细腿。禁止二足站姿、火柴腿、人类小黑腿、膝盖/脚掌/鞋感、长条身体接两根腿。
- **动作优先于摆拍**：小黑象必须在推、拉、挡、托、盖章、检查、筛选、拧紧、搬运、修补等核心动作里发力；不能只是站在物品旁边合影。
- **标签像批注，不像标题**：中文文字应贴近物品或动作，像手写批注、便利贴、下划线和小箭头。不要左右两侧放大标题，不要写完整观点句。
- **颜色只做节奏点**：彩色面积要小，通常 4-6 个小点缀即可。大面积彩色便签、彩色抽屉标签和彩色纸堆会显廉价。
- **阴影极轻**：只允许物件脚下有轻接触阴影；不要明显灰底、暗角、渐变、厚重棚拍阴影。
- **拒绝笨重感**：小黑象不应像笨重雕塑压在画面里。它要像正在认真干活的小执行者，能钻、推、拉、够、递、扛一点点东西，有轻微前倾或拉伸姿态。

## Cover 模式

Cover 版是单独的一张图，不和正文 16:9 小现场混用。参考 `_skill-staging/wechat-tech-article-infographic` 的科技感信息图要求，但把小黑象 2.0 融进去：

- **比例**：21:9 超横版，适合公众号头图/封面。
- **背景**：深色科技背景，青橙对比，弱 HUD 网格、轻微纸感、玻璃拟态卡片和发光连接线。
- **主体**：一个小黑象 2.0 真实物品隐喻作为主视觉；小黑象仍然必须四足、短象鼻、小耳朵、白点眼。
- **角色占比**：Cover 里小黑象也不能成为巨型主角。小黑象高度约 4%-6% 画面高，黑色视觉体量约为此前测试 cover 的 1/3；主视觉应由“真实主物品 + 物理链路”承担，小黑象只是执行动作的小角色。
- **构图**：标题区、核心隐喻区、底部短句区分开；主体不要压满画面，保留科技留白和清晰视觉焦点。
- **文字策略**：如果没有明确标题，生图阶段不生成长中文标题；只生成无文字或少量不可读装饰线，后续可本地叠加标题。用户给定标题时，标题短于 12 字才可尝试直接入图。
- **品牌标识**：当主题明确涉及真实品牌、产品或 App 时，真实物品可以带官方品牌 logo / app icon / 产品标识，例如飞书场景用飞书标识，Codex / OpenAI 场景用 OpenAI 标识。logo 是识别锚点，不是广告主视觉。
- **反风格**：不要正文信息图式密集节点，不要营销海报大字压满，不要无依据的伪品牌 logo、错误 logo 或 logo 抢主角，不要伪文字 HUD。

## 小黑象硬门槛

必须同时满足：

- 黑色实心小象
- 短象鼻
- 小耳朵
- 四足短圆桩腿
- 白点眼
- 非人形、非火柴人、非旧小黑

## 真实物品原则

真实物品要有摄影质感、自然光影和透视，但不能厚重。优先选择能承载动作的物品：

- 印章、放大镜、闸门、透明盒、玻璃罩
- 闹钟、钥匙、绳子、滑轮、拉杆、按钮
- 文件夹、卡片、便签、夹子、收纳盒
- 漏斗、筛子、水管、胶带、工具箱
- 积木、轨道、桥、门、货架、抽屉

如果主题明确点名真实平台或产品，主物品可以是带真实品牌标识的 app 卡片、文件夹、设备屏幕、终端 tile、文档卡、工具盒或产品包装元素。标识必须服务“这是什么工具 / 平台”的识别，不要做成品牌海报。

真实物品的“真实”来自材质、透视、接触阴影和可触碰感，不来自数量、复杂度或棚拍厚度。判断标准：

- 一眼能看清主物品是什么。
- 一眼能看清小黑象对它做了什么。
- 去掉中文标签后，仍能大致读出冲突。
- 物件之间有空气，画面不是素材拼贴。

## 反风格

不要：

- 旧版小黑 / 小黑人 / 黑色人形
- 厚重 3D 玩偶小象 / 写实小象 / 萌宠小象 / 儿童玩具公仔
- 笨重圆胖小象 / 大头大身子摆件 / 近距离角色特写
- 小黑象高度超过画面高 6% / 黑色体量过大 / 比主物品还抢眼
- 二足站立小象 / 两根人形腿 / 火柴腿 / 鞋子脚掌 / 长条身体接腿
- UI 截图 / App 截图 / 仪表盘
- PPT 信息图 / 复杂流程图 / 架构图
- 商业海报 / 科技 HUD / 赛博大屏
- 无依据的伪品牌 logo / 错误 logo / logo 抢主角 / 暗示官方背书
- 大量文字 / 长标题 / 密集标签
- 物品堆满画面
- 写实动物、萌宠、儿童卡通
- 角色或主物品占据画面过大，像商品摄影或品牌 KV
