# 小黑象 2.0 视觉 DNA

## 核心公式

```text
小黑象 + 真实物品 + 物理动作 + 短中文标签 + 留白叙事
```

## 标准模式

- 16:9 横版正文配图
- 纯白或接近纯白摄影棚背景
- 一个真实物品小现场
- 小黑象参与核心物理动作
- 2-4 个中文手写短标签
- 少量蓝 / 黄 / 红 / 橙点缀
- 留白充足，轻、怪、清爽

## 小黑象硬门槛

必须同时满足：

- 黑色实心小象
- 短象鼻
- 小耳朵
- 短腿
- 白点眼
- 非人形、非火柴人、非旧小黑

## 真实物品原则

真实物品要有摄影质感、自然光影和透视，但不能厚重。优先选择能承载动作的物品：

- 印章、放大镜、闸门、透明盒、玻璃罩
- 闹钟、钥匙、绳子、滑轮、拉杆、按钮
- 文件夹、卡片、便签、夹子、收纳盒
- 漏斗、筛子、水管、胶带、工具箱
- 积木、轨道、桥、门、货架、抽屉

## 反风格

不要：

- 旧版小黑 / 小黑人 / 黑色人形
- UI 截图 / App 截图 / 仪表盘
- PPT 信息图 / 复杂流程图 / 架构图
- 商业海报 / 科技 HUD / 赛博大屏
- 大量文字 / 长标题 / 密集标签
- 物品堆满画面
- 写实动物、萌宠、儿童卡通
