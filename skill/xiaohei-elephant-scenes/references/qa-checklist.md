# 小黑象 2.0 QA Checklist

## Critical

- [ ] 小黑象有短象鼻、小耳朵、短腿、白点眼。
- [ ] 小黑象不是小黑人、黑色人形、火柴人、旧小黑或普通黑球。
- [ ] 画面有真实物品，不是纯手绘解释图。
- [ ] 小黑象正在承担核心物理动作。
- [ ] 一张图只表达一个核心处境或冲突。
- [ ] 没有虚构未确认的人名、品牌、数据、经历和案例。

## Standard

- [ ] 背景纯白或接近纯白，留白充足。
- [ ] 真实物品少而准，不像素材拼贴。
- [ ] 主物品没有大到像商品图。
- [ ] 中文标签 2-4 个，短且可读。
- [ ] 画面不像 PPT、UI 截图、架构图或商业海报。
- [ ] 3 秒内能看懂核心动作。

## Failed Signals

- 小黑象只是站在旁边。
- 真实物品太多，动作不清楚。
- 中文文字变成长标题。
- 角色没有象鼻。
- 画面像旧版小黑人场景图。
- 需要解释很多才懂。
