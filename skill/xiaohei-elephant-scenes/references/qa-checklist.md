# 小黑象 2.0 QA Checklist

## Critical

- [ ] 小黑象有短象鼻、小耳朵、短腿、白点眼。
- [ ] 小黑象是四足小象：4 条短圆桩腿贴在身体下方，允许遮挡但不能只剩两条人形腿。
- [ ] 小黑象不是小黑人、黑色人形、火柴人、旧小黑或普通黑球。
- [ ] 小黑象不是厚重 3D 玩偶、写实小象、萌宠、公仔或商品模型。
- [ ] 小黑象看起来轻巧、有动作弹性，不是笨重圆胖摆件。
- [ ] 画面有真实物品，不是纯手绘解释图。
- [ ] 小黑象正在承担核心物理动作。
- [ ] 一张图只表达一个核心处境或冲突。
- [ ] 没有虚构未确认的人名、品牌、数据、经历和案例。

## Standard

- [ ] 背景纯白或接近纯白，留白充足。
- [ ] 真实物品少而准，不像素材拼贴。
- [ ] 主物品没有大到像商品图。
- [ ] 整体场景占比中等偏轻，不是 close-up、商品摄影、玩具棚拍或品牌 KV。
- [ ] 镜头有明显后退感，画面四周保留大块白色呼吸区，不是近距离角色/物品特写。
- [ ] 彩色点缀面积小，没有大面积彩色便签堆、彩色抽屉标签或彩色纸片铺满画面。
- [ ] 中文标签像批注，贴近动作或物品，不像左右两侧的大标题。
- [ ] 中文标签 2-4 个，短且可读。
- [ ] 画面不像 PPT、UI 截图、架构图或商业海报。
- [ ] 3 秒内能看懂核心动作。

## Failed Signals

- 小黑象只是站在旁边。
- 小黑象看起来像黑色玩具小象、萌宠小象或商品模型。
- 小黑象太圆、太大、腿太粗短，显得笨重不灵巧。
- 小黑象只有两条腿、腿像人腿/火柴腿、有膝盖脚掌鞋子，或像小黑角色加了一根象鼻。
- 真实物品太多，动作不清楚。
- 中文文字变成长标题。
- 标签过大、太远，像海报标题而不是现场批注。
- 角色或主物件太大，压住留白。
- 镜头太靠前，角色和物品像贴着观众脸。
- 彩色纸片、便签、抽屉标签过多，颜色抢过主动作。
- 背景出现灰底、暗角、渐变或厚重棚拍阴影。
- 角色没有象鼻。
- 角色没有四足小象结构。
- 画面像旧版小黑人场景图。
- 需要解释很多才懂。

## Cover Mode

- [ ] Cover 是 21:9 超横版，不混入正文 16:9 配图数量。
- [ ] 背景符合深色科技感、青橙对比、弱 HUD / 玻璃拟态 / 发光连接线方向。
- [ ] 标题区、主视觉区、底部短句区有清晰层次，不像正文节点墙。
- [ ] 小黑象仍满足四足、短象鼻、小耳朵、白点眼，不因深色科技风漂移成人形角色。
- [ ] 如果没有明确标题，画面不应生成乱码、伪文字或多余英文。
