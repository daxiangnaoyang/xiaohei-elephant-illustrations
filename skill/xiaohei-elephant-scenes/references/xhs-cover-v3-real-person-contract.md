# 3:4 小红书 V3 真人封面运行时契约

## 模式身份

本契约只适用于明确提出“小黑象 + 小红书封面 / 3:4 封面 / V3 真人封面”的请求。它是 xiaohei-elephant-scenes 的独立封面分支，不能替代标准 16:9 正文图、3:4 手绘信息图、21:9 Cover 或 9:16 视频封面。

它的目标不是复刻一张历史封面，而是把 V3 的三层稳定资产迁移到新的 3:4 主题：

V3 成品封面 -> 深蓝信号场 / 白描边 / 层级 / 光影语言
人物身份锚点 -> 同一个真人的脸型、发型、眼镜、面部比例和年龄气质
单一动作参考 -> 一个手势、半身姿态和自然手部关系
新主题 -> 新标题、新金句、新物件、新小黑象动作

## 路由边界

- 只有用户明确提出小红书封面、3:4 封面或 V3 真人封面时进入。
- 用户只说小黑象小红书信息图时，走 xhs-infographic-3x4-runtime-contract.md，不自动加入真人。
- 用户只说 9:16 视频封面时，走 9:16 分支；V3 参考不能把 9:16 成品直接裁切成 3:4。
- 没有可核验的本地 V3 成品、人物身份和动作参考时，状态为 BLOCKED，不凭空生成真人身份。

## 三类参考的输入角色

每个候选必须记录以下三类输入，且一类只承担一个职责：

| 输入角色 | 必需 | 只允许决定 | 禁止决定 |
| --- | --- | --- | --- |
| V3_COVER_STYLE_REFERENCE / STYLE_REFERENCE_ONLY | 是 | 深蓝信号场、白描边、光影、层级、真人封面质感 | 原版文字、原版线条位置、原版裁切、背景图案、底图 |
| V3_PERSON_IDENTITY_REFERENCE / IDENTITY_REFERENCE_ONLY | 是 | 脸型、侧分黑发、细金圆眼镜、面部比例、短胡须、年龄气质 | 身份图背景、服装以外的场景、原图构图 |
| V3_PERSON_ACTION_REFERENCE / ACTION_REFERENCE_ONLY | 是 | 一个手势、半身姿态、手掌方向、动作自然度 | 第二个动作、额外手臂、身份图之外的脸部改造 |

公开 Skill 不提交真人照片或个人绝对路径。运行时用本机资产注册表解析以上三个符号；项目回执可以记录本次实际使用的本地绝对路径。

## 视觉不变量

- 比例固定为 3:4，独立重新构图；不裁切、拉伸、加黑边或复用 9:16 成品作为底图。
- 真人头部必须使用 V3 的 200% 放大版本：头脸相对普通成人半身头身比例放大约 200%，但颈部、肩线、衣领和手势自然连接。身份参考只锁定“是谁”，不把自然头身比例原样复制到最终图。
- 允许使用 V3 的深蓝信号场作为背景语言，但画面不能成为纯黑底。真实物件和小黑象必须落在暖奶油纸面、浅色工作台或清晰暖边缘光中。
- 真人是中景半身识别锚点，不是巨型头像或全身小人。人物、物件和小黑象围绕一条主链组织，不做多角色海报。
- 真人轮廓在同一次生图中生成一条单一、干净、细薄的白色描边。禁止粗贴纸边、双层描边、霓虹光晕和后期描边层。
- 只保留一条“主题 -> 真人动作/真实物件 -> 小黑象物理动作 -> 结果”的主链。封面不是 3:4 信息图，不放 3-6 节点墙、仪表盘或多栏 UI。
- 小黑象 2.0 高度约 4%-6% 画面高，保持短象鼻、小圆耳、白点眼和四足短圆桩腿；象鼻必须与真实物件发生可见接触。
- 真实产品只有在主题明确点名时才使用准确官方 logo，logo 贴在对应真实物件上，尺寸克制。

## 文字与一次成型

- 主标题最多两行；金句只保留一句；必要短标签最多 3 个，每条 2-6 个字。
- 所有文字逐字进入 allowed_text，并在一次 image_gen 中和人物、物件、小黑象、白描边一起生成。
- 标题参考图只能作为 TYPOGRAPHY_REFERENCE_ONLY；V3 成品、身份图和动作图都不能当文字层、底图、mask、overlay、composite 或 merged 输入。
- 每个候选恰好一次 image_gen；禁止本地叠字、透明文字 PNG、后期修字、后期描边和拼接人物。

## 重试熔断与优先级

- 单张封面最多 8 个完整候选，第 8 版仍未满足 P0 约束时标记 NEEDS_HUMAN，不生成第 9 版。
- 约束优先级：P0 = 画幅、安全区、逐字文案、人物身份、白描边、小黑象可见性与四足；P1 = 主题主链、物件动作、缩略图可读性；P2 = 装饰、背景细节和颜色微调。
- P0 发生冲突时不通过继续增加装饰解决；优先重写构图或缩短非固定文字。固定文字无法在安全区容纳时停下交人工判断。

## QA 顺序

1. 确认 3:4 独立构图和平台安全区。
2. 逐字核对 allowed_text。
3. 核对三类参考角色没有串用、没有复制原版文字/版式。
4. 核对人物身份、单一动作、自然手部和白描边。
5. 核对暖奶油承载面、深色背景可读性、真实物件主链和小黑象 IP/尺度/接触动作。
6. 缩略图 3 秒读图和整体质感。

视觉理解默认使用 Codex 当前 GPT 系列运行时。Hermes/智谱的 scripts/qa_image.py 不能替代本分支的真人身份、白描边和全量视觉 QA；视觉 QA 不可用时标记 BLOCKED。
