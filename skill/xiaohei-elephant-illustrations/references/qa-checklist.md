# QA Checklist

## Critical

- [ ] 是 16:9 横版。
- [ ] 小黑象出现，并承担核心动作。
- [ ] 画面只表达一个认知锚点。
- [ ] 背景是纯白或接近纯白，没有纹理、阴影、渐变。
- [ ] 主体留白充足，不像 PPT 信息图。
- [ ] 中文标签少、短、能读，通常不超过 4 个。
- [ ] 小黑象不是可爱宠物象、马戏团象、写实动物、表情包或儿童绘本角色。
- [ ] 没有画入用户未提供的人名、品牌名、数据或具体经历。
- [ ] 没有复刻旧案例构图，而是为当前文章生成了新隐喻。

## Standard

- [ ] 3 秒内能看懂主题。
- [ ] 低科技物理隐喻成立，不是抽象符号堆叠。
- [ ] 颜色点缀克制。
- [ ] 橙色只用于主路径或移动关系。
- [ ] 红色只用于问题、重点、提醒或结果。
- [ ] 蓝色只用于补充说明、反馈或系统状态。
- [ ] 小黑象的动作能说明内容，不只是增加可爱感。
- [ ] 没有复刻现有示例图的物件组合和构图。

## 常见失败与修正

| 失败 | 修正 |
|---|---|
| 太可爱 | 减少表情和圆润度，强调空表情和执行动作 |
| 太像 PPT | 去掉箭头、模块框和长标题，换成物理物件 |
| 文字太多 | 保留 1-3 个短词 |
| 小黑象装饰化 | 改成小黑象正在盖章、分拣、卷线、拆箱、压实、喷洗或搬运 |
| 含混看不懂 | 增加一个明确主物件，删掉次要元素 |
| 太像旧案例 | 保留核心意思，换掉主物件、小黑象动作和空间方向 |
| 背景不干净 | 重生成并强调 pure #FFFFFF white background, no texture, no gradient |
| 中文错字 | 优先局部编辑；错得多就减少标签并重生成 |

## 交付判断

高质量图应该让读者先觉得“有点怪”，然后 1 秒内看懂结构。

如果第一眼像教程页、PPT、品牌海报或萌宠贴纸，就不合格。
