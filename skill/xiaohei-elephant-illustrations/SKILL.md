# 小黑象正文配图

## 核心定位

把中文内容里的关键判断、学习卡点、流程断点、工具选择和普通人学 AI 的处境，转译成一张张“小黑象正在认真干一件荒诞但成立的事”的正文配图。

```text
小黑象 + 认知锚点 + 低科技物理隐喻 + 少量中文批注 + 留白
```

默认输出是 16:9 横版白底手绘图。小黑象不是萌宠、表情包或吉祥物，而是普通人面对 AI 系统、任务和信息过载时的执行者。高质量成图应该先让读者觉得“有点怪”，再在 1 秒内看懂文章里的一个结构或处境。

## Before Starting

按需读取，不要一次全塞：

- `references/xiaohei-elephant-ip.md` - 小黑象 IP 母设、动作和禁忌
- `references/article-visual-strategy.md` - 文章配图位置选择和 shot list 规则
- `references/style-dna.md` - 视觉 DNA、颜色、留白、中文批注规则
- `references/composition-patterns.md` - 认知锚点和构图模式
- `references/prompt-template.md` - 生图提示词模板
- `references/qa-checklist.md` - 生成后质量检查
- `assets/examples/01-xiaohei-elephant-ip-master.png` - 第一张小黑象母设样例，只作气质参考，不照抄构图

默认规则：

- 用户只要求“想法 / 怎么配图 / 设计方案”时，先输出 shot list，不直接生图。
- 用户明确说“生成 / 出图 / 做一张 / 做几张”时，使用 `image_generate` 或可用生图工具逐张生成。
- 用户要求修改已有图时，优先用局部编辑提示，保留构图、线条、角色和留白，只改指定问题。
- 文章或项目图片资产最终归档到 `<ARTICLE_ASSET_ROOT>/<article-or-project-name>/`。
- 不能确认的个人经历、数据、品牌名和案例，不要画成事实；用概括性标签代替。

## Core Flow

### 1. 判断哪些地方值得配图

先读正文或主题，按 `references/article-visual-strategy.md` 找最值得画的点。不要平均配图，不要每个小标题都配图。优先画认知转折、流程断点、读者处境和可视化隐喻。

如果用户给的是完整文章，先列出候选配图点，再筛成 4-6 张。只给一个概念时，直接进入单张图设计。

### 2. 提炼认知锚点

每张图只选一个认知锚点：

- 用户被什么卡住、拉扯、筛选、催促、返工？
- AI 工具或流程里哪里发生了分流、断点、堆积、误判？
- 哪个抽象判断可以变成一个低科技物理动作？
- 哪 1-3 个中文短词能帮助读者 1 秒看懂？

优先选择：工具选型焦虑、信息过载、教程照做失败、任务拆解、素材分拣、提示词反复改、AI 输出验收、知识沉淀、社群答疑、项目复盘。

### 3. 输出 shot list

默认给 4-6 张。每张写清：

```text
位置：
主题：
核心意思：
构图模式：
核心物理动作：
小黑象动作：
关键物件：
中文短标签：
成图理由：
风险/避坑：
```

文章很短时 1-3 张，长文最多 8 张。不要把正文做成画册。

### 4. 单张生成

每张图单独生成，不拼成九宫格。提示词必须包含：

- 16:9 横版中文正文配图
- 纯白背景
- 黑色手绘线稿，大量留白
- 小黑象作为核心动作主体
- 低科技物理隐喻，而不是 PPT 流程图
- 少量红色、蓝色、橙色中文手写批注，最多 3 个短词
- 禁止萌宠化、表情包化、商业插画、PPT 信息图、复杂架构图

生成前如需更稳，先读 `references/prompt-template.md`。

### 5. 多图生成

一次做多张时，逐张生成，逐张 QA。不要把 4-8 张拼成一张总览图。系列图要保持同一视觉 DNA，但每张必须更换主物件、小黑象动作和构图重心，避免变成同一张图的换词版。

### 6. QA 和迭代

按 `references/qa-checklist.md` 检查。以下问题不过关就重生成或改图：

- 小黑象只是站在旁边
- 太可爱、太幼稚、太像 mascot
- 画面太满，像信息图或流程图
- 中文标签过多或错字明显
- 背景不是纯白
- 没有表达一个清晰认知动作

### 7. 保存交付

按项目归档：

```text
<ARTICLE_ASSET_ROOT>/<article-or-project-name>/01-topic-name.png
```

交付时说明：生成了几张、每张用途、保存路径、哪张最稳、哪张需要再收。

## Quality Gates

- 小黑象必须参与核心动作。
- 一张图只表达一个认知锚点。
- 中文批注通常 2-4 个短词；如果文字错误风险高，收敛到 1-3 个。
- 不虚构用户未提供的经历、数据、品牌、案例。
- 不复刻旧版小黑示例构图；只能借鉴留白、密度和工作流。
- 如果第一眼像教程页、课程 PPT 或品牌海报，不交付。
