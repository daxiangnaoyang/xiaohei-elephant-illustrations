# Generic Cover Style Library

Use one style per cover. Styles define visual language, not a fixed character position.

| # | Style | First visual center | Good for |
|---|---|---|---|
| 01 | Warm paper action scene | Title or person | Friendly explainers, onboarding, practical steps |
| 02 | Clean product explanation | Product or workflow | Tools, product walkthroughs, process teaching |
| 03 | Deep-blue signal | Title plus one abstract signal | Trends, decisions, one strong viewpoint |
| 04 | Paper story wall | One story turn | Retrospectives, before/after, lessons learned |
| 05 | Editorial whitespace | Large title | Essays, analysis, calm authority |
| 06 | Black-and-gold conclusion | Core conclusion | Frameworks, decisive points, premium editorial tone |
| 07 | Fluorescent test bench | Verified evidence or task | Experiments, comparisons, hands-on checks |
| 08 | Handwritten action desk | Action sentence | Checklists, beginner steps, exercises |
| 09 | Dark workflow system | Input → process → output | Automation, operations, system explainers |

## Shared visual rules

- Keep one first visual center and one supporting center.
- Use a clear palette of two main colors plus one accent; do not stack every effect.
- Keep interface cards abstract and free of invented data.
- Let the person interact with a real or abstract object only when that action explains the topic.
- Treat any supplied reference as a style or density cue, never as a tracing template.

## Channel adaptations

### 3:4 social cover

Use a short hook, large title, and a readable person silhouette. Leave breathing room near the bottom overlay area. Avoid placing the only critical word at the lower edge.

### 21:9 article or long cover

Use generous horizontal negative space. Place the person and title as two related blocks rather than compressing both into the center. Build this ratio directly.

### 9:16 video cover

Stack the message vertically and reserve a clean region for platform controls. Recompose from the brief; never stretch a horizontal cover.
