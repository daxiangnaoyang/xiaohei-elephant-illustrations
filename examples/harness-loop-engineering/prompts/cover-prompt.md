# 封面图 — 小黑象白底手绘版

## 视觉隐喻

Harness 是工程外壳，Loop 是让系统自己转起来的循环。封面不用科技 HUD、不用深色玻璃拟态、不用赛博背景，而是用一张白底手绘小黑象解释图表达：

```text
小黑象坐在透明外壳上，一手牵着循环线，一手指向内核。
```

读者一眼看到：模型只是里头的核心，外面的 Harness 和循环起来的 Loop 才是工程能力。

```text

不要科技 HUD，不要深色背景，不要玻璃拟态，不要真实物件摄影，不要小黑人。

小黑象一只手/象鼻牵着围绕外壳转动的循环线，另一只手/象鼻指向内核。

Visual metaphor:
```
