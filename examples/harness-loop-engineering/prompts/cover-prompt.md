# 封面图 — 生成任务

## 视觉隐喻
哈奈斯（Harness）包裹着模型。Loop 让哈奈斯自己跑起来。主体是一个半透明天体（代表模型），外面有一层有质感的工程外壳（Harness），外壳上有流动的光线和节点（Loop）。整体是一张科技感公众号封面，一眼能看出"外层比内核更重要"。
