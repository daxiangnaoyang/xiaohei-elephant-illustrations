# Harness 与 Loop 正文配图 — 4张 shot list

## 配图 1：理解 Framework/Harness/Loop 三层关系

**母版：** 05-ai-automation-badge
- 场景：三层关系的物理化表达
- 主物件：三个层层嵌套的物件——一个大号透明亚克力立方体（Layer 1 Framework），中间有一个稍小的方形外壳（Layer 2 Harness），外壳里有更小的小黑/磁流体核心（Layer 3 Loop）
- 小黑动作：小黑坐在 Harness 外壳上方，手里一根细绳牵着下面小 Loop 核心，像是在"调度它"
- 标签："零件怎么拼" / "拼好怎么不崩" / "怎么自己运转"
- 3秒读懂：有层套层的结构，小黑坐在中间层指挥内层动作

**母版锁定：**
- 母版：05-ai-automation-badge
- 抽取的不变量：真实物件质感、比例克制、小黑与物件有明确力学关系
- 当前内容变异点：①换掉工牌/身份标签→用透明亚克力立方体/外壳替代 ②空间关系从左右拉扯→上下嵌套 ③小黑动作从拉回→坐在上层指挥下层
- 要避免的失败信号：不做成图解说明图、不画三层表格、不出现太多标签文字、避免母版复刻（不和原案例的挂绳/工牌布局一样）

## 配图 2：四类生产崩溃 — 工具调用雪崩

**母版：** 02-message-overload
- 场景：工具调用雪崩——一个工具报错了，后续调用全部跟着错
- 主物件：一部 iPhone / MacBook，屏幕上显示错误弹窗，越来越多纸片从设备周围涌出来，每张纸上写着不同的工具调用记录/错误码
- 小黑动作：小黑双手挡在一堆涌出的失败记录纸片前面，身体前倾，一脸"又来了"的表情
- 标签："又崩了" / "雪崩" / "不是模型的问题"
- 3秒读懂：设备吐出一堆错误纸片，小黑快挡不住了

**母版锁定：**
- 母版：02-message-overload
- 抽取的不变量：一个出口物件作为涌出源、小黑在做挡的动作、标签点出情绪
- 当前内容变异点：①换掉"手机"→用笔记本+众多小纸片替代 ②空间关系从左右→中央偏左侧涌出右侧小黑挡 ③配件不同：不用沙漏，用堆叠写满错误的小纸片
- 要避免的失败信号：不做成聊天UI截图、不出短信界面、不复制原母版的手机+小黑+沙漏

## 配图 3：验证闭环 — 一票否决三问

**母版：** 04-code-review-rework
- 场景：内容写完了，但还有一个独立验证者在检查
- 主物件：一个复古大号红色印章，旁边是一张已经被盖了"通过"的A5卡片。另一侧一个手持放大镜对着卡片
- 小黑动作：小黑举着放大镜在看卡片上的内容，表情严肃——它不是在"看看能不能过"，而是在做决定
- 标签："自认为完成" / "被证据证明完成" / 两码事
- 3秒读懂：小黑举放大镜审查已经盖章的成果

**母版锁定：**
- 母版：04-code-review-rework
- 抽取的不变量：检查工具对已完成内容的复核关系、标签像审查意见而非流程名称
- 当前内容变异点：①换掉大放纸堆→变成一张已经盖章的卡片（简化检查对象）②空间从放大镜+纸+印章的三角形布局→改为卡片+印章在左侧，小黑+放大镜在右侧 ③小黑动作从站在检查区域→举放大镜审查已完成的卡片
- 要避免的失败信号：不做成办公素材拼贴、不复制原母版的纸堆+放大镜+红印章三角形拓扑

## 配图 4：33个 Loop — 不是手动提示，是设计循环

**母版：** 06-ai-resume-filter
- 场景：一个人不需要坐在设备前打字了，设备自己在循环执行
- 主物件：一个旧式机械闹钟，钟摆或表盘上连着无数条细线，每条线末端引向各种物件（小卡片、钥匙、玩具螺丝刀），表达"一个触发器带动了整个系统"
- 小黑动作：小黑坐在闹钟旁边，面前一杯咖啡（不是在工作），表情轻松地看着闹钟"自己在跑"
- 标签："设计循环" / "别手动提示" / "让它自己转"
- 3秒读懂：闹钟自动运转，小黑在旁边喝咖啡

**母版锁定：**
- 母版：06-ai-resume-filter
- 抽取的不变量：一个主物件有入口出口/触发关系、小黑与被触发对象有位置关系、标签精炼
- 当前内容变异点：①换掉筛子→用机械闹钟 ②空间从上下递纸→中央闹钟辐射四周 ③小黑动作不同：不是推纸入筛，而是坐着旁观
- 要避免的失败信号：不做成流程图、不画多个闹钟、不把33个Loop全摆出来、不复制原母版筛子+纸堆+小黑的拓扑
