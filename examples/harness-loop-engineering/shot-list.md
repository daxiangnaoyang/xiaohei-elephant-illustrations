# Harness 与 Loop 正文配图 — 小黑象版 shot list

> 这组示例只用于展示“小黑象 + 低科技物理隐喻 + 少量中文批注 + 留白”的正文配图方向。所有成图必须是黑色小象：短象鼻、小耳朵、短腿、白点眼。不得回退成旧版小黑、黑色人形、火柴人或真实物件小现场。

## 配图 1：完成判定处

- 生成文件：`generated/01-completion-gate.png`
- 主题：AI 输出不能只靠“自称完成”
- 读者处境：模型说任务完成，但人还不知道它是否真的可用
- 核心冲突句：自称完成不作数，证据证明完成才算数
- 构图模式：验收窗口 + 证据桌
- 小黑象动作：小黑象站在“完成判定处”窗口后，用象鼻拿放大镜检查证据
- 关键物件：完成判定窗口、放大镜、证据卡片、完成勾选卡
- 中文短标签：完成判定处 / 自称完成不作数 / 证据 / 完成
- 画面 3 秒读懂句：输出要进验收窗口，不能自己说完成就完成
- 风险/避坑：不要画成办公审批流程图；小黑象必须在检查证据，不是站岗

## 配图 2：自转与零件

- 生成文件：`generated/02-self-running-parts.png`
- 主题：系统能自己转，但底层零件不能缺
- 读者处境：看到自动化跑起来了，却忽略了底层约束和运行结构
- 核心冲突句：自己转不是魔法，是零件、边界和循环设计的结果
- 构图模式：积木底座 + 自转机器
- 小黑象动作：小黑象用象鼻把闹钟放到会自己运行的小机器旁边
- 关键物件：积木、城堡底座、自动运行小机器、闹钟
- 中文短标签：自己转 / 不崩 / 零件
- 画面 3 秒读懂句：自动化能跑起来，是因为底层零件先搭好了
- 风险/避坑：不要画成机器人巡逻图；小黑象要参与搭建或调度

## 配图 3：安全外壳

- 生成文件：`generated/03-safety-shell.png`
- 主题：Harness 是工作流的安全外壳
- 读者处境：只看模型能力，不看权限、日志、限流和熔断
- 核心冲突句：真正可用的系统，不是只有模型，而是外面那层工程外壳
- 构图模式：工具盒 / 保护盒
- 小黑象动作：小黑象用象鼻掀开一个写着“安全策略、监控告警、熔断降级”的外壳
- 关键物件：外壳盒、齿轮、权限控制、日志审计、限流保护
- 中文短标签：外圈 / 中间 / 权限控制 / 日志审计 / 限流保护
- 画面 3 秒读懂句：模型外面必须有保护壳，才不会裸奔
- 风险/避坑：不要做成复杂架构图；标签要短，像盒子上的手写标记

## 配图 4：积木城堡

- 生成文件：`generated/04-building-block-castle.png`
- 主题：Loop Engineering 是一块一块搭出来的
- 读者处境：想一次性把复杂系统搭完，结果每块都不可测试
- 核心冲突句：可用系统不是一口气堆成，而是逐块搭、逐块测、逐块替换
- 构图模式：积木城堡 + 巡逻机器人
- 小黑象动作：小黑象用象鼻把一块积木放进城堡入口
- 关键物件：积木、城堡、巡逻小机器人、待安装模块
- 中文短标签：积木 / 城堡 / 巡逻
- 画面 3 秒读懂句：复杂工作流要像搭积木一样拆成可替换模块
- 风险/避坑：不要让机器人抢主角；小黑象必须是主要执行者

## 配图 5：四类崩溃

- 生成文件：`generated/05-four-failures.png`
- 主题：崩溃不是模型一个点的问题
- 读者处境：工具链、需求、文档、临时方案同时失控，却把锅甩给模型
- 核心冲突句：真正失控的是工程系统，模型只是暴露问题的地方
- 构图模式：事故现场 + 四个失败源
- 小黑象动作：小黑象用象鼻堵住破裂水管，旁边还有文档、线缆和纸片在失控
- 关键物件：破裂水管、纸片雪崩、线缆乱团、破损需求文档、Demo 系统
- 中文短标签：溢出 / 雪崩 / 失控 / 丢失
- 画面 3 秒读懂句：多处同时崩，说明系统没有兜底
- 风险/避坑：不要把画面画太满；保留白底和足够留白
